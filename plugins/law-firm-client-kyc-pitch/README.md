# 律所 Client KYC Pitch 插件

本插件用于在律师事务所 Pitch 前开展 Client KYC / Client Intelligence 研究。它会先识别目标公司的实质业务及适用法律法规，再主动核验法定资质、许可、备案与持证主体；同时建立报告基准日全部直接/间接控制、协议控制及并表主体清单，对全集团进行知识产权基础扫描，并对核心IP开展权属链、许可、负担、争议及主体匹配深查，最后结合工商、融资、团队、同行业及负面新闻信息形成八章报告。第六章强制覆盖A股、港股、美股各不少于3家上市参照，每个市场明确1家主Benchmark和至少2家承担不同维度的相邻参照，并逐家说明选择理由、关键差异和可比局限；报告保留可点击的官方及财务来源，并在更新和Word导出时保留、嵌入来源合格的官方产品图。对企查查等计费数据源，插件会建立跨章节共享查询台账，使股东、董监高、对外投资和IP信息一次采集、多章复用，避免无必要的重复积分消耗；企查查积分不足时，基础工商和公司信息可按覆盖能力改用元典、iFind或Wind补充，不会直接写成无记录。

## 路径与加载关系

本插件采用 Codex 个人市场安装方式，存在三类用途不同的路径：

| 用途 | 路径 | 说明 |
|---|---|---|
| 插件源码 | `~/plugins/law-firm-client-kyc-pitch/` | 唯一需要维护的源文件目录 |
| 个人市场索引 | `~/.agents/plugins/marketplace.json` | 通过 `./plugins/law-firm-client-kyc-pitch` 指向插件源码；该相对路径从用户主目录解析 |
| Codex 运行副本 | `~/.codex/plugins/cache/personal/law-firm-client-kyc-pitch/<版本>/` | Codex 安装或更新时自动生成并实际加载的版本化缓存 |

市场索引与运行副本的路径不同属于正常机制，并不表示安装错误。不要直接修改运行缓存；更新插件时应修改源码目录，并在 Codex 中刷新或重新安装，使缓存同步到最新版本。

## 安装与更新

1. 保留完整插件目录，包括 `.codex-plugin/plugin.json`、`skills/`、`references/`、`templates/` 和 `assets/`。
2. 确认个人市场索引中的 `source.path` 为 `./plugins/law-firm-client-kyc-pitch`。
3. 在 Codex 的插件目录中从 Personal 来源安装或刷新本插件。
4. 更新后新建任务或重启 Codex，确认加载的是最新版本。

不要只把 `SKILL.md` 复制到普通 Skills 目录，否则会丢失插件清单、法律分析参考文件、资质矩阵模板和界面元数据。原始 ZIP 仅是导入来源；插件完成安装后，无须继续依赖该 ZIP。

## 使用示例

```text
使用 law-firm-client-kyc-pitch 完善附件企业背景调查报告。
保持原有八章目录，不新增综合结论和免责声明。
先识别实质业务及适用法律法规，主动核验应有资质、实有证照、持证主体与实际经营的匹配情况；建立控股及并表主体全集，对全集团完成基础IP扫描并深查核心IP，再形成法律分析、商业洞察和 Pitch 建议。
第六章按A股、港股、美股各不少于3家进行比较，每个市场设置1家主Benchmark和至少2家相邻参照，逐家说明可比局限，并保留可点击来源和官方产品图。
```

建议连接企查查类工商数据、Wind/iFinD 类金融数据、交易所及公告检索、监管机关和企业官网、新闻网页，以及 Word/PDF 文件处理工具。外部信息应标注来源、查询日期和证据强度；无法核验的事项不得写成确定事实。
